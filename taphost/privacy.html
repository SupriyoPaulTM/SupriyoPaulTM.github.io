LEGAL & PRIVACY

Privacy Policy

Effective Date: August 19, 2026 • Application: TapHost

1. Overview

Welcome to TapHost, developed by Suprio Paul. TapHost is a local web development environment for Android that provides local web hosting (HTTP/PHP), database management (SQLite), FTP server capabilities, and Git version control.

Your privacy is our priority. TapHost is engineered as an offline-first, client-side application. We do not operate secondary servers to collect, harvest, or sell your source code, projects, databases, or personal files.

2. Data Collection and Usage

TapHost operates primarily locally on your device:

  • Project Files & Databases: All HTML, CSS, JavaScript, PHP files, SQLite databases, and server configurations remain exclusively stored on your local device storage.
  • Network & Web Server: The local web server and FTP server run on local loopback and local area network interfaces. No project traffic passes through external servers unless you voluntarily activate an optional public tunnel.
  • GitHub Authentication: When you connect your GitHub account via OAuth or Personal Access Tokens, tokens are stored encrypted in private on-device SharedPreferences. They are used strictly to communicate directly with official GitHub APIs (e.g., cloning, pulling, and pushing repositories) on your behalf.

3. Third-Party Services and Advertisements

The free version of TapHost utilizes third-party SDKs to display advertisements and support app development:

  • Google AdMob: We use Google AdMob to serve banner and interstitial ads. Google AdMob may collect and process device identifiers (such as Advertising ID), IP addresses, and diagnostic crash data in accordance with Google's Privacy Policy.
  • Google Play In-App Billing: If you support TapHost via the Supporter Wall / In-App Purchase, the transaction is processed securely through Google Play Billing. We never receive or store your credit card or financial details.

4. Device Permissions

TapHost requests only the permissions necessary to function as a developer tool:

  • INTERNET & ACCESS_NETWORK_STATE: Required to host the local web server on your local Wi-Fi/LAN, clone Git repositories, and load AdMob ads.
  • FOREGROUND_SERVICE: Required to keep the background server process alive and stable while you test web pages in external browsers.
  • POST_NOTIFICATIONS: Used to display an active server status notification with quick stop/start controls.
  • REQUEST_IGNORE_BATTERY_OPTIMIZATIONS: Optional user-granted setting to prevent the Android OS from prematurely terminating the server process during background hosting.

5. Children's Privacy

TapHost is intended for general audiences, developers, and students. We do not knowingly collect personal identifiable information from children under the age of 13.

6. Changes to This Privacy Policy

We may update our Privacy Policy from time to time to reflect app updates or regulatory requirements. Any updates will be posted on this page with a revised effective date.
